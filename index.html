Om uppgiften

Denna uppgiften går ut på att jag som student ska få utvärdera och lära mig om olika CSS-ramverk. Jag ska i uppgiften prova på två olika ramverk med syftet att få en överblick över vilka ramverk som finns och vilka ramverk som passar bäst för olika användningsområden.

Ramverk jag använder

Bootstrap

Bootstrap är ett CSS-ramverk som erbjuder enkla sätt att skapa responsiva webbplatser. Det erbjuder en mängd komponenter och klasser som gör det lätt att skapa professionella webbplatser.

Bootstraps webbplats

Tailwind CSS

Tailwind CSS är ett CSS-ramverk som gör det enkelt att skapa responsiva webbplatser. Det erbjuder en mängd fördefinierade klasser som gör det lätt att skapa professionella webbplatser.
