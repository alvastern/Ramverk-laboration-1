Publicering

Plattform för publicering

Här beskrivs vilken plattform som användes för publicering av webbpålatsen, samt hur arbetssättet för publiceringen såg ut. Plattformen som användes var Netlify. Netlify är en plattform som inte är baserad på FTP/SFTP, utan använder istället exempelvis Github för att publicera webbplatser.

Arbetssätt

För att publicera webbplatsen via Netlify började jag med att publicera mitt projekt till Github-repository. Därefter importerade jag repositoryt till Netlify och publicerade webbplatsen. Vid publiceringen användes npm run build för att bygga de relevanta filerna som behövdes för publiceringen.
