Tailwind CSS

Om ramverket

Tailwind CSS är ett CSS-ramverk där små klasser kombineras direkt i HTML för att bygga upp utseendet. Varje klass styr en egenskap, till exempel bg-pink-200 för en ljusrosa bakgrund eller p-6 för avståndet mellan innehåll och kant. På min Tailwind-sida använder jag klasserna för att ge glassmenyn och formuläret egna färger och visa dem bredvid varandra på större skärmar.

Utvärdering av Tailwind

Fördelar

En stor fördel som jag upplevde med Tailwind är att deras sätt att definiera färger var mycket enkelt och tydligt. Det fanns ett stort utbud av färger som var enkla att definiera i HTML-koden.

En annan fördel är att jag upplevde att det var enklare att skapa en visuell design som var unik. Det var enkelt att justera färger, margin, padding etc. för att skapa något unikt.

Nackdelar

En nackdel som jag upplevde med Tailwind är att det var svårt och komplicerat att använda det till en början. Eftersom ramverk är nytt för mig är det väldigt mycket att ta in till, vilket gör att ramverket upplevs som väldigt komplicerat.
