Om ramverket

Bootstrap är ett CSS-ramverk med färdiga stilar för bland annat knappar, tabeller och formulär. På min Bootstrap-sida använder jag till exempel table-striped för att ge varannan rad i glassmenyn en annan bakgrund och form-control för att ge textfälten ett enhetligt utseende. Bootstraps rutnät gör också att formulärfälten kan ligga bredvid varandra på större skärmar och staplas på mobilen.

Utvärdering av Bootstrap

Fördelar

En fördel med Bootstrap är att jag tycker det fanns bra och tydliga instruktioner för hur ramverket skulle användas på deras webbplats. På webbplatsen fanns det även tydliga exempel som visade på hur resultatet kunde forma sig vid användning av ett visst kommando.

Även om färgpaletten var en nackdel när jag inte använde SASS, anser jag att det fanns en tydlig färgpalett med färgkoder. Hade jag använt SASS istället för CSS, hade färgen varit enkel och tydlig att använda.

Nackdelar

En nackdel som har har upplevt med Bootstrap är att färghanteringen var lite svår att förstå. Det fanns en tydlig färgpalett anpassad för SASS, men eftersom jag inte använde det blev det lite komplicerat.

En annan nackdel är att var att hanteringen för padding och margin var svår att förstå till en början. Det fanns många olika kommandon för att hantera dessa, vilket gjorde det svårt att lära sig vilka kommandon som gjorde vilka ändringar.
